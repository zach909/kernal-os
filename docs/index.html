kernal-os (KOS)

A password-first, security-focused operating system built on the Linux kernel.

Nothing happens without your password. There are no background services, no cached logins and no autostart.

Features

  • Password on everything - scrypt-derived key, full audit log.
  • Sealed apps - zip files that are never unzipped, run from memory in a Landlock + namespace sandbox.
  • Malware scanner - every install, update and write is scanned first.
  • Multi-kernel cells - separate Linux kernels in KVM micro-VMs on their own CPU cores.
  • Every line is a command - English, Spanish, French, German, Portuguese, Italian, Russian, Chinese, Japanese.
  • Encrypted boot - LUKS2 disk unlocked from a signed pre-boot environment.
