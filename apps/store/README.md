# store

Generated by `python3 suite/store_gen.py write`. Do not edit by hand: change `suite/store_data.py`.

The apps from `docs/REQUESTED_DEFAULT_APPS.txt` (the default apps of Android, iPhone, Mac, Windows 11, Linux, Apple Vision Pro, Google VR, Google Glass and the proposed iGlasses), merged by what each *does*: Messages and Google Messages are one app, Calculator is one app on every device. This folder has no `manifest.json`, so **the group has no permissions**; each app is its own folder and asks for only what it needs. They never call each other.

**88 apps: 12 do a real part of their job, 76 are screens that say what they are for and why they cannot do it yet.** None is `full`.

* **partial**: works offline for one user, in the app's own storage (or the OS's passwords store). The note says what is missing.
* **shell**: draws a screen that says what the app is for and which part of KOS it would need (a camera command, a network rule, a system service). It does nothing else, so nobody mistakes it for the real thing.

```
kos pack apps/store -o dist/store
kos install dist/store        # each asks for the password
kos permit store.notes
run store.notes
```
